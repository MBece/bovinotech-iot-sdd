## Limitación del entorno

La ejecución de pruebas HTTP basadas en `FastAPI TestClient` continúa bloqueándose en el entorno local con Python 3.13.2, incluso en una prueba aislada. Por ello se ejecutaron las pruebas unitarias directas, las pruebas Node, compilación, lint y SAST, y se dejó el contrato HTTP cubierto en los archivos de prueba para ejecutarlo en un runtime compatible o CI.

### Compatibilidad heredada corregida

La pestaña/origen anterior conservaba eventos creados con contratos previos. Inicialmente, un error 422 bloqueaba el lote completo y la interfaz mostraba `[object Object]`. La sincronización ahora procesa cada evento de forma independiente: los válidos avanzan, el incompatible permanece disponible para revisión, los errores estructurados se presentan en español y los estados históricos `CREADO`/`RECHAZADO` se normalizan como `SINCRONIZADO`/`FALLIDO`.

La revalidación final mostró dos vacunaciones heredadas como `Sincronizado` y una desparasitación incompatible con el backend antiguo como `Fallido; pendiente de reintento`, con el mensaje legible: `El tipo de evento no es compatible con la versión del servidor`. No volvió a aparecer `[object Object]`.
